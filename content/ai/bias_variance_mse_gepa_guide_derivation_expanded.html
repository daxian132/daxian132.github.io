00｜先看整体：我们到底想判断什么？

假设你有几版 Prompt，想选出以后处理真实任务时表现最好的一版。你不能只问“谁这次分数最高”，还要问“这个高分里，有多少是真能力，有多少是测量误差”。

① 目标真实能力是多少？

确定目标任务和评分标准。真实能力记作 J。

 ② 测量这次测得准不准？

用有限题目打分。偏差看中心，方差看波动，MSE 看总误差。

 ③ 选择为什么选中了它？

用带噪声的分数挑赢家，可能连正向噪声一起挑中。

 ④ 复测高分能否复现？

冻结赢家，用未参与选择的新题检查它。
全文要连起来的因果关系：测量存在波动 → 选择操作偏爱偶然高分 → 搜索中的冠军分可能偏乐观 → 需要独立复测。
同时，若评分尺本身有固定偏移，换一批题也不会自动修好它。
概念放在框架哪里？它回答的问题
Bias 偏差② 固定一个对象，反复测长期平均有没有偏离真值？
Variance 方差② 固定一个对象，反复测每次结果围绕自身均值波动多大？
MSE 均方误差② 汇总测量质量相对真值的平方误差平均多大？
Winner's Curse 赢家诅咒③ 用测量结果做选择选中以后，保留下来的噪声还平均为零吗？
独立复测④ 检查被选中的对象不再沿用被挑中的那次好运，分数会怎样？

贯穿例子：先假设每版 Prompt 的真实能力都是 80 分。这个设定故意排除了能力差异，让我们只观察“测量和选择”本身造成了什么。最后再讨论真实 GEPA 中能力会改变的情况。

接下来先不选赢家。固定 Prompt A，先分清目标任务上的“真实能力”和一批题测出的“估计值”。

① 目标 → ② 测量

01｜Bias 到底是什么？固定同一个 Prompt 来看

Bias 描述的是：固定一种评测方法，它在所有可能的评测结果下，平均会偏离真实能力多少。这里有两个不同的平均：目标任务上的真实平均表现，以及反复运行评测方法所得估计值的平均。

① 真实能力 80，是我们要估计的目标

固定 Prompt A、模型版本和运行配置。先用一个能算清答案的简化场景：目标任务分为三类，各占 1/3；A 按目标标准在这三类任务上的得分分别固定为 77、80、83。

真实能力 J = (77 + 80 + 83) / 3 = 80

如果完整覆盖这三类任务，按目标比例、用正确标准计算，结果就是 80。这个例子公开真值，是为了检查评测方法。实际中，我们通常无法评测所有未来任务，才需要抽一批题，用样本平均分估计 J。

② 一小批题测到 82，只能说明本次误差是 +2

每轮从目标分布中独立抽 n = 3 道题，每道题属于三类任务的概率均为 1/3。假如这一轮有两道题来自 A 得 83 分的任务类别，一道来自得 80 分的类别：

本轮估计值 Ĵ = (83 + 83 + 80) / 3 = 82
本次误差 = Ĵ − J = 82 − 80 = +2

这个 +2 可能只是这批题恰好更适合 A。下一批题可能更多来自得 77 分的类别。单次误差不等于 Bias。随机抽三道题不代表完整覆盖三类任务，也不保证它们恰好各占 1/3。

③ 反复小样本测试后平均为 82，是否就有 Bias？

保持 Prompt 和评测规则不变，每轮重新独立抽三道题。做 R 轮，就得到 R 个估计值。将它们再平均，是有限次实验的平均。

有限次平均 = (Ĵ₁ + Ĵ₂ + … + ĴR) / Rn 是每轮测多少道题；R 是整套评测重复多少轮。它们不是同一个数量。

例如连续三轮都碰巧得到 82，三轮平均也会是 82。它仍然可能是随机波动，不能据此断言这个方法的 Bias 就是 2。已知真值时，有限次平均可以用来估计偏差，但这个偏差估计本身也有不确定性。

Bias 定义里的 E[Ĵ] 是期望：把这个方法所有可能产生的估计值，按各自发生的概率加权平均。在这里，独立重复的轮数越来越多，有限次平均会趋近这个期望；不是每增加一轮都更接近，也不要求在某个有限轮数时恰好相等。

量平均的是谁？在这个例子里
真实能力 JA 在目标任务上的得分，按目标分布加权确定为 80
一次估计 Ĵ这一批评测题上的得分可能是 82，也可能是别的值
有限次实验平均实际做过的 R 轮估计值仍然随机，可能是 82
期望 E[Ĵ]所有可能的估计值，按发生概率加权由目标和评测方法决定；理想抽样求均值时为 80

④ 为什么理想的小样本评测也可以无偏？

用 X 表示 A 在随机一道目标任务上的得分。三类任务等可能，所以 E[X] = (77 + 80 + 83) / 3 = 80。每轮按相同分布抽 n 道题，按正确标准评分并直接求平均，则：

E[Ĵ] = E[(X₁ + … + Xn) / n]
= (E[X₁] + … + E[Xn]) / n = 80
Bias = E[Ĵ] − J = 80 − 80 = 0

即使每轮只测一道题，这个估计方法也无偏。小样本使分数更容易忽高忽低，但在这里不会让它长期偏高。无偏不代表每次准确；本次得分离 80 很远，也不代表方法有偏。

⑤ 长期中心为什么会是 82？必须指出评测偏移的机制

继续固定 A，并按相同的目标分布抽题。现在换成一个存在系统偏移的 Judge：它对每道答案的评分，都比目标标准高 2 分。评测报告使用这些 Judge 分数的平均值，想估计的目标仍是原标准下的能力 80。

Judge 给出的平均分 = 目标标准下的样本平均分 + 2
E[Judge 给出的平均分] = 80 + 2 = 82
Bias = 82 − 80 = +2

长期中心为 82 的原因现在明确了：Judge 相对目标标准系统性多给分。另一种偏移机制是评测集过多包含 A 擅长的任务，却仍直接求平均、没有按目标任务比例校正。

“全量评测完，不就应该是 80 吗？”在这个得分固定的例子里，完整覆盖目标任务并按正确标准、正确比例汇总，确实是 80。如果覆盖完整，但仍用每题多给 2 分的 Judge，报告就会是 82。目标能力没有改变，改变的是测量它的方法。

Bias 属于“目标 + 抽样规则 + 评分与汇总规则”这套估计流程。重复实验是理解和检查它的一种方式，不是重复到某个次数后才产生 Bias；若概率模型已知，也可以直接计算期望。这里的“多给 2 分”是为说明原因而设定的例子，不是断言实际 Judge 一定如此。

⑥ 把这些区别放回同一个得分公式

真实评测中，J 是固定 Prompt、模型和运行配置，在目标任务分布上的期望得分；Ĵ 是这轮有限题目得到的估计值。模型生成也可能随机，有限题库也可能不代表未来任务，因此现实中的“测完当前题库”不一定等于知道真实能力 J。

记 μ = E[Ĵ]，则 b = μ − J 是 Bias，ε = Ĵ − μ 是本轮相对方法自身中心的波动：

观测分 = 真实能力 + 长期偏移 + 本次随机波动
Ĵ = J + b + ε

J：我们想知道的量

例如真实能力是 80。对固定的 Prompt 和目标任务分布，J 是固定值。

b：长期偏移

例如评分者长期多给 5 分。即使题目足够多，平均分也会靠近 85。

ε：这次的随机波动

这批题刚好更擅长，或这次生成更顺利，可能额外高出 3 分；下次也可能偏低。

例如这次测到 88 分，可以拆为 80 + 5 + 3。但在真实评测中，你通常只看得到 88，看不到这三个分量。本文用已知真值的例子，是为了看清机制。

为什么可以这样拆？b 和 ε 分别如何定义？

固定同一个 Prompt，反复重新抽取评测数据，并重做具有随机性的生成、评分过程。把所得 Ĵ 的长期平均记为 μ = E[Ĵ]。

b = μ − J，　ε = Ĵ − μ
因此 Ĵ = J + b + ε，且 E[ε] = 0

这里 E[·] 是对“整套评测过程的重复”取平均。b 是固定估计流程的偏差；ε 围绕该流程自己的长期平均上下波动。这是一个分解定义，不要求噪声一定服从正态分布。

若题目确实独立来自目标分布，而且评测奖励就是我们定义 J 时使用的目标奖励，样本均值是无偏的，b = 0。讨论数据分布不匹配或 Judge 固定偏移时，实际测量流程已不完全等同于理想目标流程。

下一节沿用“Judge 每题多给 2 分”这个明确机制，逐项算出固定 Prompt A 的 Bias、Variance 和 MSE。

② 测量 · 暂时固定 Prompt A，不做选择

02｜反复测同一个 A：三个量看同一组结果

为了列出全部可能性，将上一节简化为每轮只测一道题，三类目标任务仍各以 1/3 的概率出现。按目标标准，A 的得分为 77、80、83，期望为 80。现在改用每题多给 2 分的 Judge：

目标标准下的得分Judge 报告分：目标得分 + 2发生概率
77791/3
80821/3
83851/3

因此 79、82、85 是这个方法所有可能的输出，不是碰巧测了三次的记录。按概率加权后的期望是 82，目标真值仍是 80。这就是同一个 Prompt A、同一套目标任务，由评分标准的偏移产生 Bias 的具体过程。

Bias：方法的期望偏了多少？

固定多加 2，使期望从 80 移到 82；目标真值仍为 80。

Bias = 82 − 80 = 2

单位是“分”。每轮报告值都比该题的目标得分多 2，但相对总体真值的本次误差未必是 2。

Variance：围绕中心多散？

相对自身均值 82，偏离为 −3、0、+3。

Variance = (9 + 0 + 9) / 3 = 6

单位是“分²”。方差参照的是 82，不是 80。

MSE：离真值有多远？

相对真值 80，误差为 −1、+2、+5。

MSE = (1 + 4 + 25) / 3 = 10

单位也是“分²”。平方防止正负误差抵消。

MSE = Bias² + Variance = 2² + 6 = 10同一组测量结果：先看长期中心，再看围绕中心的波动，就能解释总平方误差。
把三个概念放回同一个式子：Ĵ − J = b + ε。Bias 描述 b；Variance 描述 ε 的大小；MSE 描述两者合起来造成的平方误差。MSE 是汇总量，不是第三种误差来源。
逐步推导：为什么交叉项会消失？
  1. 先明确对象。此处 Prompt 固定，所以真值 J 固定。μ = E[Ĵ] 也固定，只有本次测量 Ĵ 随数据变化。
  2. 加减同一个 μ，把误差拆开。
    Ĵ − J = (Ĵ − μ) + (μ − J) = ε + b
    前半段是这次相对自身均值的波动，后半段是均值相对真值的偏移。
  3. 平方，保留交叉项。
    (Ĵ − J)² = ε² + 2bε + b²
  4. 对重复评测取期望。
    E[(Ĵ − J)²] = E[ε²] + 2bE[ε] + b²
    b 是常数，可以提出期望；E[ε] = E[Ĵ − μ] = μ − μ = 0。
  5. 认出剩下的两项。
    MSE = E[ε²] + b² = Var(Ĵ) + Bias²
    这是有限二阶矩下、固定目标估计的恒等式。没有假设每次 ε 都等于零。

上例把三个等概率结果当作完整的教学分布，所以方差除以 3。用有限样本估计未知总体方差时常见的 n−1 分母，是另一个问题。RMSE = √MSE，用来把平方单位还原成“分”。本文也不是在推导预测新标签时含有不可约噪声项的那一套预测误差分解。

样本量 n 为什么出现在下一步实验里？

如果每道题得分的标准差为 σ，n 道题的得分独立同分布，则样本平均分的方差和标准误差分别是：

Var(Ĵ) = σ² / n，　SE = σ / √nSE 是平均分估计值的标准差，单位为“分”。它不是单道题得分的标准差 σ。

例如 σ = 20：测 25 道题时 SE = 4；测 100 道题时 SE = 2。增加题目主要让 ε 变小，不会自动让 b 变小。如果 Judge 长期多给 5 分，多测题只会更稳定地得到偏高分数。

σ²/n 适用于这里的独立同分布抽样。从有限题库中不放回抽题时，方差需要有限总体修正；若目标就是该题库的平均分，每道题得分固定，测完全部题并准确求平均后，抽样方差就是零。重复题、相关任务、复杂抽样或共享随机因素也会改变方差；重复运行相同题目不能等同于增加同等数量的新题。

现在切换观察对象：下一节先去掉固定加分，让每个候选的测量都无偏，再每轮比较 A、B、C、只记录赢家。我们要检查：即使单个候选没有 Bias，“按最高分挑一个”这条新规则会不会产生 Bias？

③ 选择 · 从“固定 A”切换到“本轮赢家”

03｜无偏的测量，为什么会选出偏高的赢家分？

为把选择作用单独看清，这一节设 b = 0，并让每个候选的真值都等于 80。一次评测可能得到：

候选真值 J本轮噪声 ε观测分 Ĵ选择结果
A80−476未选中
B80+181未选中
C80+686本轮赢家

这里选中 C 的原因是：它恰好拿到了最有利的噪声。它的真值仍然是 80，选择这个动作没有把它的能力从 80 提升到 86。

一轮例子还不够：用四种情况证明“长期偏高”

只考虑 A、B 两个候选。各自的噪声独立地以一半概率取 −4 或 +4。于是下面四种情况等概率发生。每轮都保留观测分更高者；平局随意选。

② A 低、B 高768484+4

分数为 76、76、84、84，平均 80。正负噪声抵消，测量无偏。

每轮只记录赢家

分数为 76、84、84、84，平均 82。被保留的噪声平均为 +2。

这就是连接前后文的关键：固定 A 的 ε 平均为零，不代表“挑出来的那一个 ε”平均也为零。选择规则改变了我们统计哪一批结果。

这种“根据带噪声分数选赢家，再用同一个分数描述赢家能力”导致的高估，本文称为选择后的乐观偏差，也常用 Winner's Curse（赢家诅咒）来描述。这里的“选择”指选模型或 Prompt，不是另一个话题中的人群抽样偏差。

把“选中谁”和“保留什么噪声”写成公式

用 I 表示本轮赢家的编号。I 会随评测结果变化；arg max 表示“返回最大值对应的编号”。先保留一般式：

Ĵi = Ji + bi + εi
I = arg maxi Ĵi
ĴI − JI = bI + εI

固定候选 i 时，E[εi] = 0；被选中的编号 I 却取决于这些噪声，所以不能直接推出 E[εI] = 0。

只有在本节“所有 Ji = 80，所有 bi = 0”的特例里，选最高分才等于选最大噪声：

ĴI = 80 + maxi εi
选择乐观量 = E[ĴI − JI] = E[maxi εi]

两个独立 ±4 噪声的例子中，这个期望就是 2。只有一个候选，或所有候选噪声完全相同时，没有由挑最大值额外产生的乐观量。零均值且有实际噪声差异的多个候选，可以出现严格为正的乐观量。

与 MSE 的关系：上面的两候选例子里，赢家分的 Bias = 2、Variance = 12，因此 MSE = 2² + 12 = 16。固定 A 的 MSE 也是 16：选择产生了正偏差，但并不意味着任何情形下 MSE 都一定增大。

若候选真实能力不同，赢家的 JI 本身也随 I 变化，不能直接套用“固定真值”的 Var(Ĵ) + Bias²。始终可先定义误差 e = ĴI − JI，再用 E[e²] = Var(e) + E[e]²；这与只计算 Var(ĴI) 不是一回事。

为什么要“冻结赢家，再独立复测”？

第一轮选中了 C，就固定 C，不再选一次。用一批没参与选择的新题测 C，相当于重新抽一个误差 η，而不是重复使用刚才的 +6。

复测分 J̃I = JI + bI + ηI若复测数据和随机性独立于搜索，且同一候选的新测量误差均值为零，则新误差不再因为先前选中了它而偏正。

在本节 b = 0、真值都为 80 的设定下，赢家复测的期望是 80。一次复测仍可能是 77 或 83，甚至高于原来的分数；我们说的是长期规律，不是保证每次下降。

复测的两个边界：它不会消除相同评分尺的系统偏移 b；也不能把同一批旧题再跑一次，就说抽样噪声已经独立。若看完复测结果又改 Prompt 或重新挑赢家，这批数据又参与了选择。

实验将完整演示这三列：固定候选的测量分、选中赢家的旧分数、冻结赢家后的新分数。滑块只改变这条链中的一个因素。

② 测量 → ③ 选择 → ④ 复测 · 同一例子的可操作版本

04｜把测量、选择、复测完整跑一遍

固定不变：所有候选的真实能力 J = 80，单题波动尺度 σ = 20。默认评分尺无偏 b = 0。每轮先给 N 个候选打分，选最高分，再用独立新噪声复测这个赢家。模拟里没有训练，因此能力不会因为“多选了几次”而提高。

先按顺序点下面三个按钮，观察“选择额外乐观量”，再自己拖动滑块。

改变②测量：题越多，单个平均分的标准误差 SE = 20 / √n 越小。
改变③选择：每个候选都要测 n 道题。N 增大时总预算也增大，不是固定总预算比较。
进阶：评分尺偏移和共同噪声分别改变哪一环？

b 控制评分尺。给所有候选固定多加 5 分，不改变谁胜出，但搜索分和独立复测分都会整体提高 5 分。

ρ 控制候选之间的噪声相似程度。如果某一批题让所有候选恰好多得同样的分，这部分“共同运气”不改变排名。只有候选间不同的噪声会影响谁被选中。这里保持每个候选自身的 SE 不变。

用于验证：换新题不能修好一把有固定偏移的尺子。
0%：各自波动；100%：每轮所有候选一起升降。这不是同一个候选内部题目之间的相关性。
εi = SE × [√ρ Z共同 + √(1−ρ) Zi]Z 为独立标准正态变量。该构造保证 Var(εᵢ) = SE²、候选间相关系数为 ρ。它是说明机制的等相关模型，不是对真实评测集的完整刻画。

模拟口径与边界：为什么它不能预测真实 GEPA 会掉几分？

这是连续得分的高斯教学模型，不是正确率或严格限制在 0–100 的分数。正态噪声可能让单轮分数超出 0–100；计算不截断，图条以 120 为显示上界。所有候选能力相同，只为隔离选择作用。

采用固定随机种子。生成 1,000 组噪声及其相反数，组成 2,000 轮配对模拟；这样会抵消共同噪声和固定候选的有限模拟均值，便于比较滑块。配对轮次并非相互独立，不能用“2,000 个独立样本”的公式计算置信区间。独立复测噪声使用另一组随机数，配对均值也会抵消。

参数变化复用同一组基础随机数，方便单因素比较。样本量 n 通过 SE 改变噪声大小；本模拟没有逐题生成数据，也没有实现反思、变异、训练或 Pareto 选择。

实验解释的是：评测噪声如何经过选择变成乐观分数。GEPA 接下来要回答的，是这条链在真实搜索流程中分别出现在哪里。

把同一张地图映射到真实流程

05｜GEPA 并没有换一个统计问题：它让测量参与了反复搜索

把 GEPA 暂时理解为一个 Prompt 优化流程：运行候选、收集反馈、反思并提出修改，再评测候选、决定如何继续搜索。它使用评测信号，因此同样要区分能力变化和测量误差。这个流程概括来自 GEPA 官方指南。

① 定义目标什么算更好？

确定真实任务分布、奖励和评分规则。

② 执行测量得到反馈与分数

有限题目和随机执行产生有误差的观察。

③ 搜索与选择改写、比较、保留

候选内容和后续搜索方向会依赖先前观察。

④ 独立报告冻结后再检验

未参与搜索的数据用于检验最终方案。

先纠正一个会误导理解的简化：GEPA 的候选选择不等于“每一步都挑最高平均分”。官方默认的 pareto 策略根据候选在不同评测项上的优势，采样下一步要修改的父候选；另有按验证总分选父候选的 current_best 等策略。前面的 arg max 实验是选择偏差的最小例子，不是 GEPA 算法复刻。参见 官方候选选择说明。

为什么不同选择策略，仍然需要这套误差框架？

因为只要搜索方向受有限评测数据影响，就可能适配其中的偶然特征。真实搜索会产生真改进，也可能利用数据中的噪声；两者可以同时存在。前面“所有能力都为 80”的实验刻意没有真改进，所以能单独展示后一种机制。

看见搜索分上升 ≠ 已经分清：真实能力提高 / 评分偏移 / 被选择的好运

这是从统计机制推导出的评测建议，不是宣称 GEPA 必然过拟合或必然下降。真实候选能力不同，候选还会根据反馈自适应生成，所以不能把模拟的 N 或乐观分数直接代入某次 GEPA 运行。模型选择准则本身可能被过拟合，是 Cawley 与 Talbot 的模型选择研究讨论的通用问题。

按发生位置处理，而不是把所有问题都叫“bias”

链上的位置要排查什么？对应动作这个动作解决不了什么？
① 目标 / ② 测量数据不代表真实任务；Judge 长期偏向某种答案检查样本代表性、奖励定义和人工校准，必要时按目标分布加权仅增加题数不能修正错误目标
② 测量题少、生成随机性大，候选分数不稳定增加有效样本、重复运行；在同题上做配对比较并估计差值的不确定性固定种子只改善复现性，不代表消除了方差
③ 搜索与选择反复根据同一批题选候选、调参数、决定停止把这些数据都视为开发数据，记录搜索过程和预算Pareto、固定题集或低偏差评分都不是“不会过拟合”的保证
④ 最终复测报告是否仍使用了参与选择的分数冻结最终候选、奖励和协议；使用独立且有代表性的测试题，报告不确定性一次复测仍有噪声；评分尺偏移仍可能保留

一个可以直接照着执行的评测安排

  1. 开发阶段：用于反思的样本和用于挑选候选的验证样本，都可能影响最终结果。名字叫“验证集”，不代表它没有参加选择。
  2. 冻结阶段：确定最终 Prompt、模型版本、生成参数、评分规则与统计方法。
  3. 报告阶段：用没有参与上述决定的测试数据，评估基线和最终方案；优先在相同测试题上比较两者，按题目相关性和抽样方式报告适当的不确定性。
  4. 继续开发时：若看了测试结果又修改方案，这批测试数据就进入开发流程，不能继续把下一次结果说成完全独立的最终检验。

现在链条闭合了：Bias、Variance、MSE 解释测量；Winner's Curse 解释选择如何改变被保留的误差；独立复测检查高分是否能脱离原来的选择过程。

06｜用四个问题，检查这条链是否真的连起来了

A 的真实能力是 80，反复小样本评测后的平均是 82，就说明 Bias = 2 吗？

如果只是有限轮实验的平均为 82，仍可能是随机波动，不能直接当作精确的 Bias。从目标分布随机抽题、按目标标准评分并求均值时，理论期望为 80，Bias 为 0，即使每轮只测一道题也如此。若 Judge 每题固定多给 2 分，理论期望才变成 82，Bias 为 2。在得分固定的例子里，全量按目标标准正确汇总仍是 80；全量却仍用偏移的 Judge 评分，就会报告 82。

一个 Prompt 真值 80，这次测到 88。可以直接说 Bias = 8 吗？

不能。8 是本次误差，可能由长期偏移 b 和随机波动 ε 共同组成。Bias 要看固定评测流程反复运行后的长期平均减去真值。

每个候选都无偏，挑出来的最高分也一定无偏吗？

不一定。固定编号 i 的噪声均值为零，与按分数选择的编号 I 的噪声均值为零，是不同命题。两个 ±4 噪声候选的完整例子中，各自均值 80，赢家均值却是 82。

把赢家放到独立测试集上，就能解决所有误差吗？

不能。独立测试避免重复使用搜索时挑中的同一份噪声，但测试仍有抽样波动；相同 Judge 的固定偏移、目标分布不匹配也可能仍在。若又按测试分选候选，选择问题会重新出现。

以后看到一个“最高分”，按这个顺序追问：
它测的是我的真实目标吗？ → 测量波动有多大？ → 它从多少次比较中被挑出来？ → 冻结之后，有没有独立复测？
